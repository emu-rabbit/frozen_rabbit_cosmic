`verified: 2026-09-06`

## 採用內容

使用者明確採用原開局掌握為 v2.3，並要求接入正式 Web、準備對外整合內容、更新 FAQ 與新增演算法介紹頁。正式 identity 為 `generic-craft-external-reference-v2.3.0`，直接共用 `exp-opening-recovery` 實作，沒有新調參，未加入已撤回的 Deferred／Confirmed 修補。

完整品質證據仍由 [原 64-seed 報告](opening-recovery-s64-review-20260906.md) 擁有：hard-quality 滿品質由 6,309 增至 6,379，92 勝／22 敗，淨增 70 件；收益集中於部分家族，仍有退步。這次採用驗證不算新的品質確認樣本，也不宣稱已達裝備上限。

## 接線與相容性

| 邊界 | v2.3 更新 | 是否變更介面 |
| --- | --- | --- |
| 公開 Rust `main_solver` | recommend 與實際 observe 均使用 v2.3 | 否；API 仍為 `frozen-rabbit-main-solver-api-v1`，設定、狀態與結果型別不變 |
| Web Worker／WASM | 正式 policy 常數與 WASM 一起更新 | 否；ABI 仍為 `rust-web-planner-abi-v1`，函式、請求／回覆欄位不變 |
| 策略識別 | 改為 `generic-craft-external-reference-v2.3.0` | 值有變更；呼叫端若檢查或傳送舊 v2.2 字串，必須同步更新 |
| Application／Cargo | 維持 0.1.0 | 不把 solver 版本當作套件版本或 Git tag |

既有 Rust 整合可更新函式庫原始碼後重新編譯；沒有新增必填參數。既有 WASM 整合需更換求解器檔案及版本常數，不能只換 WASM 卻繼續傳 v2.2 請求。更新後開始新製作，避免兩版快取與進行中 session 混用。正式 bridge 保持版本不合即拒絕，不暗中接受舊身份。

v2.2 及原開局掌握研究 identity 均保留，不改寫歷史結果。對外說明同步於 [Rust 整合指引](../../native/craft-kernel/README.md) 的中／英文更新段落；根目錄 README 未修改。

## 對外檔案

`node tools/package-main-solver/run.mjs` 產生 `dist/main-solver-v2.3.0/`：

- `native/craft-kernel/`：公開 Rust API、求解器原始碼、範例與測試；不包含 target 或研究執行資料。
- `native/craft-kernel-web/`：既有 WASM bridge 原始碼。
- `frozen_rabbit_craft_kernel_web.wasm`：正式 production module，613,388 bytes。
- `INTEGRATION.md`、MIT 授權、Artisan 的第三方授權聲明。
- `manifest.json`：policy／API／ABI、遷移提醒與 73 個檔案的 SHA-256。

另提供 `dist/main-solver-v2.3.0.zip`。這是目前 checkout 的本機原始碼與 WASM 交付包，不是已推送的 Git tag 或 registry release；Git dependency 的遠端 main 不會因本機修改自動更新。包內 Rust 函式庫已用獨立 target 目錄執行離線 `cargo check --lib` 通過。

## FAQ 與演算法頁

新增 `#/algorithm`，由 FAQ 第一題的「這裡」站內連結前往，可返回 FAQ。四語系同步：繁體中文保留使用者給定 FAQ 文字，英文、簡體中文、日文對齊語意。介紹頁分六段說明基礎規則、滿品質收尾、等待／冒險前的比較、v2.3 提前掌握、依實際回報重算，以及測試與能力限制；沒有將評測 identity 或研究參數塞進一般閱讀內容。

瀏覽器已核對 FAQ 跳轉、四語系介紹標題／內容，以及繁中深色、英文與日文淺色 360px 閱讀。360px 無文件橫向溢出；修正過 scoped 深色選擇器未生效的問題。這是本機正式建置預覽，不是公開網站、真實手機或遊戲內驗證。
