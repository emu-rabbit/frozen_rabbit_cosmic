# v2.2 採用與 Web 接線紀錄

`verified: 2026-09-06`

## 決定與範圍

使用者在讀取 Artisan continuation 64-seed 結果後，明確要求將完整候選訂為 v2.2、接上 Web 並提交。採用 identity 為 `generic-craft-external-reference-v2.2.0`，行為沿用 `generic-craft-external-reference-exp-artisan-continuation`，沒有在採用時調參。Application／Cargo package／ABI／mechanics 版本各自管理，本次不替它們改版，也不代表網站已發布。

v2.2 包含資源收尾證明、最多 12 招的完整路線提案與全宣告球色驗證，以及 hard-quality 狀態的 Artisan 續作抽樣比較。Artisan 仍是 fallback；抽樣比較不提供必成保證。v2.1 與描述性實驗保留原身份，歷史報告不改寫成 v2.2。

`main_solver` 的 recommend／observe 與 Web protocol 均切換 v2.2，Web 四語系 FAQ 同步說明新策略。正式 Web bridge 仍只接受目前採用 policy；三個實驗僅能透過明確的 `research-web-policies` Cargo feature 啟用。Benchmark 預設目前採用版本，也可明確指定研究 identity。

## 採用依據

完整結果由 [64-seed 判讀](artisan-continuation-s64-review-20260906.md) 擁有；[全部切片](artisan-continuation-s64-slices-20260906.json)、[四表](artisan-continuation-fresh-s64.md) 與 [跑前契約](artisan-continuation-s64-prerun-contract-20260905.md) 保留獨立用途。

- 50 families × 5 equipment × 2 assumed worlds × 64 seeds；Balanced、80 actions。32,000 paired cases／96,000 fresh episodes，50/50 shards 完成。
- Hard-quality：v2.1 為 5,801/8,960；只加完工證明的 reference 為 5,828；完整 continuation 為 6,309（70.41%）。完整候選對 reference 淨增 481 件、+5.37 個百分點，580 勝／99 負。
- 品質收益在兩 world、五裝備與十四個 hard-quality family 各自淨正；仍有十個負向格子，每格淨少一至兩件。F36／F46 仍有大量失敗，沒有證據將其直接判為裝備上限。
- Hard-quality 雙側滿品質的 5,729 配對，相對 reference 平均少 2.62 招；action-limit 減少，但 terminal failed 增加。沒有全量動作序列可報等球技能減少率。
- 完整候選 native 1,450,845 次推薦：p50 8.3813 ms、p95 23.1724 ms、worst 71.5413 ms；沒有 policy-null、illegal、重試或 timeout。四 worker active wall 約 2 小時 12 分 54 秒。

這些是指定 IID world 的有限樣本成果，不是遊戲自然成功率、每一條球序優於前版或接近最優的證明。

## 驗證與成本

| 驗證 | 結果 |
| --- | --- |
| Rust format、release build | 通過 |
| `cargo test --offline --manifest-path native/craft-kernel/Cargo.toml --lib --tests` | 140 tests 通過，包含新證明／續作、alias replay 與私有球色資訊邊界 |
| `npm run build` | data verify、完整 typecheck、production WASM、Vite 與 SEO 通過 |
| `npm run test:release` | 19 files／120 tests 通過，直接載入正式 WASM |
| 正式 native↔WASM 對照 | 50 episodes／2,353 recommendations，技能與最終 context 0 差異 |

Production WASM 的 Node 量測見 [benchmark](v220-production-wasm-20260906.json)：612,472 bytes；warm recommendation p50 **5.6596 ms**、p95 **16.2868 ms**、worst **32.6584 ms**。這批只有每 family 一案，不能替代完整長跑尾端，也不包含 browser Worker、UI、手機或網路成本；不能拿來主張 WASM 一定比 native 快。

沒有新部署、正式網站查核、目標裝置或遊戲內實測。v2.2 採用與網站公開發布是不同決定。
